# 管理員後台概覽與權限說明

歡迎進入 **臺科大機器人研究社** 管理員後台系統。本指南旨在協助社團幹部快速掌握各項後台審核、庫存盤點、帳號權限管理與公告課程維護之標準作業程序。

---

## 1. 管理員角色與權限架構

| 身份層級 | 權限範圍 | 適用幹部 |
| :--- | :--- | :--- |
| **管理員 (Admin)** | 審核器材借用、機器預約、財務報帳初審、維護器材盤點總表、發布系統公告、編輯課程講義。 | 社長、副社長、教學長、財務長、總務、美宣 |

---

## 2. 後台操作三大原則

1. **落實實體點收**：所有線上核准與歸還操作，皆必須與實體物品交接或發票收取同步進行，嚴禁未點收即先點選按鈕。
2. **操作稽核紀錄**：系統內所有審核、退回理由填寫、金額修改與密碼重設操作，皆會自動記錄操作者學號與時間戳記。
3. **退回務必註明理由**：若需拒絕或退回社員的申請（如單據不合規、機台時間衝突），請在退回備註中提供具體改善指引，方便社員修正重新提交。
