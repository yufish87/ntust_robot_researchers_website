# 人員管理、公告發布與課程維護

## 1. 人員與身份組管理

- **新成員註冊碼管理**：
  - 每學期迎新繳費後，幹部可在此產生一組或多組「註冊驗證碼」，並設定使用次數上限與有效期限。
  - 將驗證碼分發給已繳費的新成員進行帳號註冊。
- **身份組變更**：
  - 可將社員身份提升為幹部或變更特定角色。
- **強制重設密碼**：
  - 若社員發生嚴重忘記密碼且無法存取信箱之極端情況，管理員可手動將該帳號密碼重設為其「學號」，並要求其登入後立即修改。

---

## 2. 系統公告發布

1. **建立公告**：輸入公告標題、分類（社課 / 活動 / 賽事 / 維修）與內文。
2. **附加檔案**：可依需求附上雲端硬碟簡章或活動報名連結。
3. **發布控制**：編輯確認無誤後，將狀態設為「**發布**」，該公告即會同步顯示於首頁跑馬燈與公告專區。

---

## 3. 課程系統管理

1. **建立社課項目**：輸入課程主題、學期別（如 `114-1`）與講師資訊。
2. **講義與資料綁定**：附上 Google Drive 講義下載連結與相關程式庫網址。
3. **錄影回放上傳**：若該堂社課有錄影存檔，貼上 YouTube / 雲端影片播放連結。
4. **閱覽權限設定**：可將錄影回放設定為僅限登入社員觀看，保護社團教學資源。

---

## 4. 許願池與問題回覆

- 定期檢視社員於許願池留下的器材採購建議、工作坊主題或系統 Bug 回報。
- 作為幹部例會提案與改善社團營運的重要依據。
