# 人員管理、公告發布與課程維護

## 1. 人員與身份組管理

- **社員名單與狀態檢視**：
  - 檢視全體註冊成員之學號、真實姓名、系所年級、身份角色（member / admin / owner）、註冊時間與最近登入時間。
- **新成員註冊碼管理**：
  - 每學期迎新繳費後，幹部可在此產生一組或多組「註冊驗證碼」，並設定使用次數上限與有效期限。
  - 將驗證碼分發給已繳費的新成員進行帳號註冊。
- **身份組變更**：
  - 可將社員身份提升為幹部或變更特定職位標籤。
- **強制重設密碼**：
  - 若社員發生嚴重忘記密碼且無法存取信箱之極端情況，管理員可手動將該帳號密碼重設為其「學號」，並要求其登入後立即修改。

## 2. 系統公告發布與推播渠道

在建立或編輯公告時，除了設定標題、分類與內文外，彈窗下方提供**三大訊息推播渠道開關**，幹部可視公告重要程度自由搭配：

1. **Email 全體社員（學校信箱／自訂信箱）**：
   - **功能**：由系統自動寄發格式化 HTML 圖文公告通知信。
   - **偏好過濾機制**：系統在寄出前**會逐一比對每位社員的個人通知偏好**。若社員在「個人設定」中已將「社課與重要公告」之 Email 開關關閉，系統會自動跳過，不寄送郵件給該社員。
   - **收件地址優先順序**：優先寄送至社員於個人設定填寫之「自訂通知信箱」；若未填寫，則寄送至學校官方信箱（`學號@mail.ntust.edu.tw`）。
2. **LINE 個人官方帳號（個人推播）**：
   - **功能**：向社員個人推送專屬設計之 LINE 圖文訊息卡片。
   - **雙重防護條件**：
     1. 該社員必須**已完成官方帳號綁定**（具備有效之 LINE User ID）。
     2. 該社員在個人通知偏好中的「社課與重要公告」LINE 開關**必須為開啟狀態**。
     若社員未綁定或已關閉 LINE 通知，系統將自動略過，不打擾社員。
3. **LINE 社員大群群播（群組廣播）**：
   - **功能**：透過社團機器人，將公告卡片同步廣播發布至社團成員交流 LINE 大群。
   - **特性**：此為群組廣播，只要身在大群內的成員皆可看到，**不受個人偏好開關限制**。適合發布全社重大社務或緊急集合通知。

> [!IMPORTANT]
> 系統公告發布後，若勾選任何推播選項，背景程式將即時進行批次分發。請在點擊送出前確認標題與內容無錯別字。

## 3. 課程系統管理與開課群播

1. **建立社課項目**：輸入課程主題、學期別（如 `114-1`）、授課日期、地點與講師資訊。
2. **講義與資料綁定**：附上 Google Drive 講義下載連結與相關程式庫網址。
3. **錄影回放上傳**：若該堂社課有錄影存檔，貼上 YouTube / 雲端影片播放連結。
4. **閱覽權限設定**：可將錄影回放設定為僅限登入社員觀看，保護社團教學資源。
5. **社課同步推播**：
   - 新增或更新課程時，同樣支援勾選「Email 全體社員」、「LINE 個人官方帳號推播」與「LINE 社員大群群播」。
   - 推播卡片將自動帶入社課主題、日期、地點、講師與講義連結，社員可點擊卡片直接進入課程頁面下載。

## 4. 通知推播機制與社員偏好運作原理

為保障社員體驗並符合個人資料使用規範，系統後端具備完整的通知分發引擎：

- **嚴格尊重個人偏好**：除了 LINE 社員大群為公開群組發布外，所有個人向之 Email 信件與個人 LINE 推播，**100% 依據社員在「自訂通知偏好訂閱中心」的開關決定**。
- **動態預設原則**：
  - 未綁定 LINE 之社員：Email 預設全開（防止漏接）。
  - 已綁定 LINE 之社員：LINE 全開，Email 預設僅保留財務報帳（減少信件轟炸）。
- **幹部無須手動過濾**：幹部發布公告或社課時，勾選「Email 全體社員」代表「以全體活躍社員為發送對象池」，系統會自動在後端逐一過濾掉已關閉該類別通知的社員，幹部可放心勾選發送。
