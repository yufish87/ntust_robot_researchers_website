# 人員管理、公告發布與課程維護

## 1. 人員與身份組管理

- **社員名單與狀態檢視**：
  - 檢視全體註冊成員之學號、真實姓名、系所年級、身份角色（member / admin / owner）、註冊時間與最近登入時間。
- **新成員註冊碼管理**：
  - 每學期迎新繳費後，幹部可在此產生一組或多組「註冊驗證碼」，並設定使用次數上限與有效期限。
  - 將驗證碼分發給已繳費的新成員進行帳號註冊。
- **匯出學校社團社員名冊 (CSV)**：
  - 專為上傳至學校學生社團資訊系統設計，符合官方標準格式：`姓名,學號,屬性,職稱`。
  - 自動依選定學年（如 114、115 等）篩選在冊社員與幹部，自動映射屬性（社長、副社長、幹部、社員）與幹部職稱。
  - 支援即時文字預覽、一鍵複製貼入學校匯入框，或匯出 UTF-8 BOM 編碼之 `.csv` 檔案。
- **身份組變更**：
  - 可將社員身份提升為幹部或變更特定職位標籤。
- **強制重設密碼**：
  - 若社員發生嚴重忘記密碼且無法存取信箱之極端情況，管理員可手動將該帳號密碼重設為其「學號」，並要求其登入後立即修改。

## 2. 系統公告發布與推播渠道

在建立或編輯公告時，除了設定標題、分類與內文外，彈窗下方提供**LINE 訊息推播渠道開關**，幹部可視公告重要程度自由搭配（依系統規範，公告已取消寄送 Email，避免信件遭退信或阻擋，改以 LINE 為主力）：

1. **LINE 個人官方帳號（個人推播）**：
   - **功能**：向社員個人推送專屬設計之 LINE 圖文訊息卡片。
   - **雙重防護條件**：
     1. 該社員必須**已完成官方帳號綁定**（具備有效之 LINE User ID）。
     2. 該社員在個人通知偏好中的「社課與重要公告」LINE 開關**必須為開啟狀態**。
     若社員未綁定或已關閉 LINE 通知，系統將自動略過，不打擾社員。
2. **LINE 社員大群群播（群組廣播）**：
   - **功能**：透過社團機器人，將公告卡片同步廣播發布至社團成員交流 LINE 大群。
   - **特性**：此為群組廣播，只要身在大群內的成員皆可看到，**不受個人偏好開關限制**。適合發布全社重大社務或緊急集合通知。

> [!IMPORTANT]
> 系統公告發布後，若勾選任何推播選項，背景程式將即時進行批次分發。請在點擊送出前確認標題與內容無錯別字。

## 3. 課程系統管理與開課群播

1. **建立社課項目**：輸入課程主題、學期別（如 `114-1`）、授課日期、地點與講師資訊。
2. **講義與資料綁定**：附上 Google Drive 講義下載連結與相關程式庫網址。
3. **錄影回放上傳**：若該堂社課有錄影存檔，貼上 YouTube / 雲端影片播放連結。
4. **閱覽權限設定**：可將錄影回放設定為僅限登入社員觀看，保護社團教學資源。
5. **社課同步推播**：
   - 新增或更新課程時，支援勾選「LINE 個人官方帳號推播」與「LINE 社員大群群播」。
   - 推播卡片將自動帶入社課主題、日期、地點、講師與講義連結，社員可點擊卡片直接進入課程頁面下載。

## 4. 通知推播機制與社員偏好運作原理

為保障社員體驗並符合個人資料使用規範，系統後端具備完整的通知分發引擎：

- **以 LINE 即時推播為核心**：日常社務通知、社課預告、重要公告與機臺/器材審核結果，一律透過 LINE 官方帳號與社員大群進行推播，避免信件遭到阻擋或漏接。
- **Email 使用範圍限制**：電子郵件僅用於「新社員註冊 OTP 驗證碼」與「忘記密碼重設驗證碼」。若社員未填寫個人信箱且為臺科大學生，系統一律自動預設為學校信箱（`[學號]@mail.ntust.edu.tw`）。
- **嚴格尊重個人偏好**：除了 LINE 社員大群為公開群組發布外，所有個人向之 LINE 推播，**100% 依據社員在「自訂通知偏好訂閱中心」的開關決定**。社員可隨時自由配置各事件項目之接收意願。
