# 器材借用審核與盤點作業

## 1. 器材借用審核管理

管理員進入「器材借用審核」頁面後，透過頂部的籤頁依序處理各階段申請：

```
[籤頁 1: 待審核] | [籤頁 2: 借用中] | [籤頁 3: 歷史紀錄] | [籤頁 4: 全部]
```

### 操作步驟
1. **待審核清單**：
   - 檢視社員申請的器材項目、數量、借用期限與理由。
   - **核准**：點擊綠色「**核准**」按鈕，申請單會立即轉移至「借用中」籤頁。
   - **拒絕**：若庫存不足或理由不合規，點擊紅色「**拒絕**」按鈕，並填寫具體退回原因。
2. **借用中清單（實體點交與歸還點收）**：
   - 此區顯示所有已核准且器材正在社員手中的單據。
   - **歸還點收操作**：
     1. 確認社員將實體器材歸還至社辦或歸還給幹部。
     2. 現場清點配件是否完整、測試功能是否正常、無短少。
     3. 確認無誤後，於該筆單據點擊「**歸還**」按鈕，系統將自動回補庫存並將單據歸檔至歷史紀錄。

---

## 2. 器材庫存與盤點維護

器材長與總務幹部可在此進行社團資產全生命週期管理：

1. **新增品項**：採購新器材時，建立新器材總表項目（輸入器材名稱、類別、規格描述與圖片）。
2. **編號入庫**：系統會為每台實體設備賦予獨立編號，幹部需要將在設備上清楚標示器材名稱與編號。
3. **設備狀態維護**：若器材在使用中損壞或送修，請即時將該獨立編號的狀態切換為「**維修中**」或「**已報廢**」，系統會自動將其自可借用池中剔除。
4. **定期盤點**：學期初與學期末可配合盤點功能進行資產全面清點。
