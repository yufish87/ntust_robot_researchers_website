# 財務報帳申請與核銷指南

本社為支援社員參與各項國內外機器人競賽、社團專案研發及社課耗材採購，提供線上財務報帳核銷系統。

---

## 1. 報帳四大類別與適用範圍

在建立報帳申請時，請依據支出性質選擇正確的報帳類別：

| 報帳類別 | 適用情境與說明 |
| :--- | :--- |
| **一般報銷** | 日常社團營運雜支、社課實作用品、行政耗材、社辦公用工具購置。 |
| **社團內部競賽報銷** | 參與社團內部舉辦之技術競賽、黑客松或社內專案開發之材料費核銷。 |
| **上銀競賽報銷** | 經社團核可代表本社參加「上銀智慧機器手競賽」專案團隊之專款專用材料報銷。 |
| **暑期營隊報銷** | 社團籌辦暑期營隊活動、機器人工作坊所產生之課程教材與活動支出。 |

## 2. 發票與單據開立鐵律

向學校或社團核銷經費時，單據必須完全符合政府與臺科大主計室規範：

> [!IMPORTANT]
> **臺灣科技大學報帳統一編號與抬頭：**
> - **統一編號 (統編)**：`04126516`
> - **買受人抬頭**：`國立臺灣科技大學`

### 各類單據合規要點：
1. **電子發票證明聯**：
   - 必須打上學校統編 `04126516`。
   - 若發票本體未列出購買品項中文明細，**請務必向店家索取並保留「銷貨明細表」**。
2. **傳統二聯式／三聯式統一發票**：
   - 三聯式發票須完整保留**第二聯（扣抵聯）**與**第三聯（收執聯）**，兩聯皆須繳交。
   - 買受人抬頭須手寫或列印「國立臺灣科技大學」，統編填寫「04126516」。
3. **紙本長條發票（收銀機發票）**：
   - 需印有學校統編，並有中文品名或附上銷售明細清單。
4. **免用統一發票收據**：
   - 必須蓋有店家的「**免用統一發票專用章**」（含統一編號、店名、地址、電話）以及「**負責人私章**」。
   - 買受人抬頭請填寫「國立臺灣科技大學」，統一編號填寫「04126516」，日期不可空白。
   - 品名請填寫繁體中文品名，不可只寫英文代號或雜項。

## 3. 線上報帳申請步驟

```
[1. 線上建立申請] ➔ [2. 幹部線上初審] ➔ [3. 繳交實體發票並回報] ➔ [4. 財務核對與撥款結案]
```

### 第一步：進入報帳申請頁
1. 點擊側邊欄進入「**財務報帳**」。
2. 點擊標題列右上角的「**新增申請**」。

### 第二步：填寫基本資訊與發票資料
1. **報帳類別**：選擇「一般報銷」、「社團內部競賽報銷」、「上銀競賽報銷」或「暑期營隊報銷」。
2. **支出詳細說明**：簡述此筆支出的用途（例如：*2026 TDK 盃機器人循跡車輪與傳感器材料採購*，至少 5 字）。
3. **發票種類**：選擇「電子發票」、「紙本長條發票」、「二聯式發票」、「三聯式發票」、「免用統一發票收據」或「其他證明文件」。
4. **發票號碼**：輸入發票字軌號碼（例如：`AB-12345678`，免用發票收據可填寫收據流水號或留空）。
5. **發票／單據日期**：選擇單據開立之正確日期（不可大於今天）。

### 第三步：新增費用明細品項
在「費用明細」區塊點擊「**新增項目**」，填寫採購的各項品名（可新增多筆）：
- **品名**：繁體中文品名（例如：*MG996R 金屬齒輪伺服馬達*）。
- **規格／詳細說明**：補充型號或規格。
- **支出類別**：選擇「文具費」、「印刷費」、「工具費」、「器材費」或「消耗性材料費」。
- **數量與單價**：輸入數量與單價，系統會自動加總計算出整筆申請的總金額。

### 第四步：上傳單據憑證畫面
- 拍攝並上傳清晰的發票／收據照片。
- 照片需清楚可見：**買受人抬頭、統一編號、日期、金額、中文品名明細與店家印章**。
- 確認無誤後點擊「**提交申請**」。

## 4. 報帳進度追蹤與四大核銷階段

| 階段 | 系統狀態標籤 | 說明與社員應執行之動作 |
| :--- | :--- | :--- |
| **第一階段** | 審核中 | 申請已送出，財務幹部正在線上審核單據照片與明細合規性。 |
| **第二階段** | 已通過 | 線上初審通過！請準備實體發票正本前往社辦繳交。 |
| **第三階段** | 已提交（發票） | 將實體發票投入社辦發票袋（或交給財務長）後，**務必至系統該筆單據點擊「回報已投遞發票」**。 |
| **第四階段** | 已撥款（結案） | 財務長清點實體單據無誤，將款項匯入您的帳戶並於系統標記撥款完成，全案結案。 |

## 5. 常見退件原因與防雷指南

> [!WARNING]
> - **統編錯誤或漏打**：未打統編 `04126516` 或號碼、發票訊息打錯者，學校主計室無法核銷，將直接退件。
> - **發票照片模糊**：上傳之照片無法清楚辨識金額或品名。
> - **未保留銷貨明細**：熱感應電子發票無品項明細且未附銷貨明細單。
> - **忘記系統回報投遞**：實體發票已交給社辦，但未在系統點擊「回報已投遞發票」，導致財務幹部無法進行後台核銷配對。
