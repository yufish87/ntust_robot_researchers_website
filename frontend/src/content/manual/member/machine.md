# 機臺設備借用指南

社辦設有 **Creality Ender 3 S1 Pro 3D 列印機** 與 **FLUX Ador 雷射切割機** 等數位自造設備，供社員製作機器人機構零件、感測器固定座、電路外殼與競賽車體。

為確保機臺運作順暢、時段不衝突並維護操作安全，使用前須於系統提出借用申請。

---

## 1. 機臺總覽與即時排程檢視

進入側邊欄「**機器借用**」，您可以：
- **檢視機臺即時日曆**：透過日曆檢視器查看本週／本月各機臺已被預約佔用的時段，申請時請避開已佔用區間。
- **重新整理排程**：點擊右上角「**重新整理**」即時更新最新預約狀態。
- **追蹤個人借用進度**：於下方列表檢視個人申請單狀態（待審核、已核准、已完成、已取消、已退回）。

## 2. 3D 列印機借用申請 (3D Printer)

### 步驟一：耗材規範與事前切片準備
1. **耗材種類與挑選規範**：
   - **社團 3D 列印線材以社辦現場現有耗材為主，不接受指定或挑選材料種類與顏色**。
   - 目前社團主要提供之線材種類為 **PETG**。
   - 若社員自備特殊線材（例如 TPU、特殊色 PLA 等），請於申請表單的用途說明內備註載明，社團可能否決特殊線材的借用申請。
2. **切片軟體**：建議使用 Creality Print、Orca Slicer 或 Ultimaker Cura 等切片軟體。
3. **輸出 Gcode 檔**：將您的 3D 模型設定好列印參數後，匯出為 `.gcode` 格式檔案（檔案大小上限為 30MB）。
4. **擷取切片預覽截圖**：截取軟體中顯示的模型放置朝向、支撐結構分佈、層高設定以及預估列印時長與耗材重量畫面。

### 步驟二：線上表單填寫步驟
1. 進入「**機器借用**」➔ 點擊右上角「**借用 3D 列印**」。
2. 填寫借用資訊：
   - **列印用途說明**：填寫工件名稱與專案用途（例如：*機器人車輪輪轂與編碼器固定支架*）。
   - **填充率 (Infill)**：例如 `20%` 或 `40%`。
   - **預估列印時間**：例如 `2 小時 45 分鐘`，若需列印多份，切片軟體計算的總時長需乘以份數，並且需自行保留列印準備、收拾、列印失敗等時間。
   - **預估耗材重量**：例如 `65g`，切片軟體重量需乘以份數。
   - **開始使用時間**：選擇您預計到社辦開機的日期與時間（系統將推算結束時間，並進行排程防撞檢驗）。
3. **初學者／新手協助**：若您初次使用該機臺或對調平、換線操作不熟悉，請務必勾選「**需要人員協助操作**」，幹部將於現場給予教學協助。
4. **上傳檔案**：上傳準備好的 `.gcode` 檔案與切片預覽截圖。
5. **確認送出**：點擊「確認送出申請」，等待幹部審核通過。

### 步驟三：現場列印與維護守則
- **首層確認**：開機列印後，**請務必在機臺旁觀察第一層（First Layer）列印完全黏著且無翹曲後**，方可從事其他作業。
- **冷卻後取件**：列印完成後，請等待熱床降溫至室溫（< 35°C）再輕輕彎曲彈簧鋼板取件，切勿高溫硬拔以免傷及熱床塗層。
- **清潔環境**：取件後請清理熱床上的裙邊（Skirt）、支撐廢料，並將工具歸位。

## 3. 雷射切割機借用申請 (Laser Cutter)

### 步驟一：適用材料確認與切削特性
本社配備之 FLUX Ador 二極體雷射切割機，**僅能切割以下材質**：

- **黑胡桃木**
- **檜木**
- **膠合板**
- **密集板**
- **黑色壓克力**
- **紙板**
- **皮革**
- **布料**
- **竹材**

> [!IMPORTANT]
> **材質切削特性與加工注意事項：**
> - 部分材質需**多次切割**才能有效切穿；降低切割速度或增加切割次數可提升可加工厚度。
> 1. **木材**：木材的切割表現會因含水量與木質密度而異。
> 2. **壓克力**：Ador 僅能切割**深色不透明壓克力**；**無法切割透明或淺色壓克力**。
> 3. **厚紙板**：厚紙板高度易燃；切割前可於表面少量加濕，並由操作人員全程看管。
> 4. **皮革與布料**：皮革與布料高度易燃；加工時請勿超過原廠建議之最大厚度，並由操作人員全程看管。
> - 詳情可參閱 [FLUX Ador 官方規格頁面](https://tw.flux3dp.com/ador/)。

> [!CAUTION]
> **雷射切割絕對禁止加工材質清單：**
> - **嚴禁切削**：**PVC（聚氯乙烯）**、**PC（聚碳酸酯）**、**含氯塑膠**、**人工皮革**、**玻璃纖維**、**碳纖維**、**金屬板材**。
> - **原因**：上述材料經雷射高溫燃燒會釋放**劇毒光氣**、**高腐蝕性鹽酸氣體**，嚴重危害人體呼吸道健康並造成機臺光學鏡片與機構不可逆之損壞！

### 步驟二：事前圖檔準備
1. **設計圖檔格式**：請準備向量切割路徑檔案（支援 `.dxf`、`.svg`、`.ai`、`.pdf`）或高解析點陣雕刻圖（`.png`）。
2. **材料厚度確認**：確認加工板材厚度並規劃切削參數。

### 步驟三：線上表單填寫步驟
1. 進入「**機器借用**」➔ 點擊右上角「**借用雷射切割**」。
2. 填寫借用資訊：
   - **雷切用途說明**：說明切割工件名稱與專案（例如：*車體底盤黑色壓克力結構件切削*）。
   - **材料來源**：選擇使用社團公用庫存或自備材料。
   - **材料種類**：例如 `椴木板`、`黑色壓克力`。
   - **材料厚度**：例如 `3mm`、`5mm`。
   - **預估加工時間**：包含排版、對焦測試與實際雷切的總預估時間（例如：`40 分鐘`）。
   - **開始使用時間**：選擇預約時段。
3. **初學者／新手協助**：若對 Flux Beam Studio 軟體參數設定或焦點校準不熟悉，請務必勾選「**需要人員協助操作**」。
4. **上傳圖檔**：上傳設計圖檔與切割預覽。
5. **確認送出**：點擊「確認送出申請」。

### 步驟四：現場操作定位與排煙安全守則（實體操作鐵律）

1. **機臺定位（推至室外開放空間）**：
   - 進行雷射切割時，**必須將雷射切割機（連同其專用桌）推移至社辦外側靠近體育館一側的室外走廊開放空間**（如下圖紅框區域所示）。
   - **排煙設置**：請接上機臺後方的排煙管，並將出風口朝向外側通風空間。

![雷射切割機放置位置示意圖（社辦外側靠近體育館走廊開放空間）](/image/manual/laser_cutter_location.png)

2. **安全防焰與全程看管**：
   - **嚴禁擅自離場**：**雷射切割機運轉期間，操作人員全程嚴禁離開機臺視線範圍！**
   - **火警應變**：若發現材料持續起火或火花異常過大，請立即按下機臺「**緊急停止按鈕（E-Stop）**」或暫停鍵，並通知現場幹部處理。
   - **清理善後**：加工完成後，請將底下的廢料落塊與焦油殘渣清理乾淨，並將機臺與桌子推回社辦內歸位。
